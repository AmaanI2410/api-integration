# 🌐 API Integration Assignment – GLOBAL TREND

This project demonstrates consuming a public REST API, caching the response, filtering results, and viewing details through a simple CLI interface.

---

## ✅ Features
- Fetches data from **two public API endpoints**:
  - `/posts`
  - `/users`
- Stores the results in **cache.json**
- CLI Options:
  - List all posts
  - Filter posts by `userId`
  - View detailed post by ID
- Full error handling for:
  - Timeout
  - Network errors
  - Invalid JSON
  - Missing data

---

## 🛠 Tech Stack
- Python 3.x  
- Requests Library  
- JSON File Caching
